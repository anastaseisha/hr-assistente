# HR-Ассистент — frontend MVP

## Требования

- Node.js 20.19+ или 22+
- npm

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес, выведенный Vite (обычно `http://localhost:5173`).

## Проверка и сборка

```bash
npm run typecheck
npm run build
npm run preview
```

## Маршруты

| Путь | Страница |
| --- | --- |
| `/` | Обзор |
| `/candidates` | Список кандидатов и фильтры |
| `/candidates/anna` | Карточка Анны Соколовой (также `maxim`, `elena`, `dmitry`) |
| `/adaptation` | План адаптации 30–60–90 |
| `/vacancies`, `/analytics`, `/settings` | Заглушки для будущих этапов |

## Структура

```text
src/
  components/   # общий layout и UI-элементы
  data/         # демонстрационные данные
  pages/        # страницы и маршруты
  types/        # TypeScript-типы
  main.tsx      # точка входа и маршрутизация
  styles.css    # стили и адаптивность
```

## Поведение демо

- Переходы, фильтрация кандидатов и просмотр карточек работают локально.
- Оценка рекрутера и отметки задач адаптации работают в памяти браузера и сбрасываются при обновлении.
- Кнопки импорта, AI-скрининга и приглашения на интервью показывают уведомление, но **не отправляют запросы**.
- Сведения об AI-оценке и объяснениях — макетные примеры, а не результаты обработки резюме.
- Из паспорта проекта предусмотрены будущие интеграции hh.ru, SuperJob и GigaChat. Не отправляйте реальные персональные данные в демо.
